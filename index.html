Stardew Save Sync Tracker

Local-only tracker for Stardew Valley saves. GitHub friendly. No upload. No server.
How syncing works
Click Select Save Folder and choose your folder like %AppData%\StardewValley\Saves\FarmName_123456789. Chrome/Edge can remember permission, so when you reopen this tracker from GitHub, click Refresh Selected Save and it reads your local save again. If another person uses this website, they select their own save. Their progress stays local to their browser.
